<h3 align="center"><b>RALLY X</b> is a fast-paced 3D arcade rally racing game built with <b>Unity 6</b> and <b>C#</b>.</h3>

<p align="center">Pick a car in the garage, attack forest and desert stages against AI rivals,<br>earn credits, upgrade, unlock — and go again.</p>

<img src="docs/readme/ui/stats.svg" width="100%" alt="3D arcade rally · Unity 6 · C# · PC · URP">

<a name="install"></a>
<img src="docs/readme/sections/10-install.svg" width="100%" alt="10 — Install">

<h3>01&nbsp;&nbsp;Clone the repository<br>02&nbsp;&nbsp;Open with Unity <code>6000.3.25f1</code><br>03&nbsp;&nbsp;Open <code>MainMenu.unity</code><br>04&nbsp;&nbsp;Press <b>Play</b></h3>

<details><summary><b>DETAILED SETUP</b></summary>

1. **Clone** — `git clone https://github.com/mokshkhokawat10-art/RALLY-X.git`
2. **Install Unity** 6000.3.25f1 via Unity Hub
3. **Add project** from disk in Unity Hub
4. **Open** `Assets/Scenes/MainMenu/MainMenu.unity`
5. **Play** ▶
6. **Build** — File → Build Profiles → Windows

</details>
